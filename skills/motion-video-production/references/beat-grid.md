# 박 격자: 음악 BPM에 맞춰 컷 길이 정하기

## 계산

- 1박 길이(초) = 60 / BPM
- 144 BPM이면 1박 = 0.4167초, 4박(1마디) = 1.6667초
- 컷 길이는 박 수 x 1박 길이로 정합니다. 예: 144 BPM에서 4박 컷 = 1.667초, 6박 컷 = 2.5초

`scripts/beat-grid.py`가 계산을 대신합니다.

```
python3 scripts/beat-grid.py grid 144 90          # 1박·1마디 길이
python3 scripts/beat-grid.py snap 144 1.7 26.0    # 초 값을 가까운 박 위치로 맞춤
```

## 조립 규칙

1. 컷의 시작 시간은 박 위치(정수 박)에 놓습니다.
2. 음악의 큰 변화(드롭)와 마지막 히트 시간은 기획 단계에서 정하고, 그 지점에 컷 전환을 둡니다.
3. 컷을 자르거나 늘려서 길이가 바뀌면 이후 모든 컷의 시작 시간을 다시 계산합니다.
4. 장면 속도를 조정할 때는 0.9~1.1배 안에서만 합니다. 이 범위를 넘으면 동작이 부자연스럽게 보입니다.
5. 생성한 음악의 실제 BPM은 생성 도구가 표기한 값과 다를 수 있습니다. 파형에서 박 17개(간격 16개)가 걸린 시간을 재고 BPM = 16 × 60 ÷ 걸린 초로 계산합니다. 어긋나면 `atempo`로 속도를 보정한 뒤 격자에 올립니다.

## 음악을 격자에 조립할 때 (ffmpeg)

음악 일부 구간을 잘라 목표 시간에 놓는 기본 형태입니다.

```
ffmpeg -i music.mp3 -filter_complex \
 "[0:a]atrim=<시작>:<끝>,asetpts=PTS-STARTPTS,aresample=48000,adelay=<ms>|<ms>[s0]; \
  [s0]amix=inputs=1:normalize=0,apad=whole_dur=<총길이>,asetpts=N/SR/TB,atrim=0:<총길이>[out]" \
 -map "[out]" -ac 2 -ar 48000 music_grid.wav
```

`asetpts=N/SR/TB`가 없으면 `adelay`가 무시되어 출력이 `총길이`보다 짧아지고 음악이 0초에서 시작합니다. (ffmpeg 9.0.2 기준)

여러 구간을 이어 붙일 때는 구간마다 `[s0]`, `[s1]`을 만들고 `amix=inputs=N`으로 합칩니다. 구간 경계에는 0.03초 안팎의 `afade`를 넣어 클릭 소리를 막습니다.
