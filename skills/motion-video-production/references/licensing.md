### Grok Imagine (SuperGrok)
출처: https://x.ai/legal/terms-of-service (요약 확인)

확인한 내용
- 약관 요약: 사용자는 Input과 Output에 대한 소유권을 보유하되 "법이 허용하는 범위에서, 사용자와 회사 사이에서"로 한정됨.
- 상업 이용: 출력물을 상업적으로 이용할 수 있으나, 약관 요약에는 "permission을 받고 Brand Guidelines에 따라 서비스로 생성했음을 표기(attribute)"해야 한다는 취지의 문구가 있었음. 이 조건이 개인 구독자(SuperGrok)에게 어떻게 적용되는지는 **미확인**입니다. 원문과 Brand Guidelines를 직접 확인합니다.
- 회사는 사용자 콘텐츠를 제품 개선과 모델 학습 등에 사용할 수 있는 광범위한 권리를 가지며, 로그인한 사용자는 학습 사용 여부를 설정에서 선택할 수 있다고 표기됨.
- 허용 가능 사용 정책(Acceptable Use Policy)에 위반되는 콘텐츠는 생성할 수 없음. 실존 인물, 미성년자 등에 대한 구체 규정은 별도 정책에 있으며 **미확인**.
- 구독 결제는 자동 갱신되고 이미 낸 금액은 법이 요구하는 경우를 제외하고 환불되지 않는다고 표기됨.
- SuperGrok 구독과 xAI API 결제가 별개 상품인지, 플랜별 해상도(720p/480p)·클립 길이 제한: **미확인**. 구독 화면에서 확인합니다.

### ChatGPT 이미지 생성 (OpenAI)
출처: https://openai.com/policies/row-terms-of-use/ (요약 확인. 이 URL은 미국·EU 외 지역용 약관 문서이며, 한국 사용자에게 적용되는 약관 문서 지정은 **미확인**)

확인한 내용
- 사용자는 Input에 대한 권리를 유지하고 Output을 소유하며, OpenAI는 Output에 대해 가진 권리가 있다면 사용자에게 양도한다고 표기됨.
- 유의점 1: Output은 고유하지 않을 수 있고, 다른 사용자가 유사한 Output을 받을 수 있으며 양도는 다른 사용자의 Output에는 미치지 않음.
- 유의점 2: 사람이 만들지 않은 Output을 사람이 만든 것처럼 표시하는 것은 금지됨. (영상 공개 시 AI 생성 사실을 숨기지 않는 것이 안전합니다.)
- 유의점 3: OpenAI와 경쟁하는 모델을 개발하는 데 Output을 쓰는 것은 금지됨.
- 유의점 4: Output의 정확성과 용도 적합성은 사용자가 평가해야 함.
- 이미지 생성에 특화된 콘텐츠 정책(실존 인물, 저작물 캐릭터 등)의 세부 내용: **미확인**.

공통 주의
- 생성한 이미지·영상이 제3자의 저작물, 상표, 실존 인물과 닮은 경우의 책임은 사용자에게 있습니다.
- AI가 만든 결과물에 한국을 포함한 각 국가의 저작권이 인정되는지는 **미확인**입니다.
- 광고·수익 채널에 공개하는 경우 각 플랫폼의 AI 생성물 표시 규정도 따로 확인해야 합니다 (이 문서에서는 **미확인**).
