# 비용 분기 규칙: 무료 먼저, 유료는 필요한 곳만

요금과 플랜 조건은 자주 바뀝니다. 아래 표는 구조(역할별 선택 기준)이고, 현재 가격과 약관은 `references/licensing.md`의 출처 링크에서 작업 직전에 다시 확인합니다.

## 역할별 도구 선택

| 역할 | 예시 도구 | 시안(무료로 시도) | 최종본(상업 공개) |
|---|---|---|---|
| 캐릭터 시트·키프레임 | ChatGPT 이미지 생성, Grok Imagine 이미지 | 이미 구독 중인 서비스를 사용 | 구독 약관의 생성물 이용 조건 확인 |
| 영상 변환 | Grok Imagine (SuperGrok 구독) | 구독 중이면 웹·CLI에서 직접 생성 | 구독 약관의 생성물 이용 조건 확인 |

| 모션 그래픽 조립 | Remotion | 개인·직원 3명 이하 영리 조직·비영리는 무료 | 4명 이상 영리 조직은 Company License |

## 분기 규칙

1. **시안은 무료로**: 대본, 음성 톤, 음악 분위기를 정하는 단계는 무료 플랜의 크레딧 안에서 끝냅니다.
2. **최종본은 공개 방식으로 결정**: 영상을 상업적으로 공개하는지(광고, 수익 채널, 판매 페이지) 먼저 정합니다. 상업 공개라면 음악과 목소리 도구의 유료 플랜을 올린 뒤 최종 음원·음성을 다시 생성합니다. 무료 플랜에서 만든 파일을 나중에 유료 플랜으로 올려도 소급 적용된다고 가정하지 않습니다. 해당 도구의 약관에서 확인합니다.
3. **구독과 API는 별개**: 웹 구독이 있어도 API·자동화 연결에는 별도 결제나 별도 키가 필요할 수 있습니다. 자동화가 막히면 웹·CLI에서 직접 생성하고 파일만 현재 에이전트가 조립합니다.
4. **해상도·길이 제한 확인**: 영상 생성 도구는 플랜별로 해상도(예: 720p/480p)와 클립 길이 제한이 다를 수 있으므로 시작 전에 확인합니다.
5. **일괄 생성 전 승인**: 장면 여러 개를 한 번에 생성하기 전에 예상 크레딧을 알리고 사용자 승인을 받습니다.
6. **키와 계정 정보 보관**: API 키는 `.env`에만 두고 저장소·프롬프트·로그에 넣지 않습니다.
