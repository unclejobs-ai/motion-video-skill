# 아트 디렉션: carry, 모션 어휘, 스타일

영상 하나에는 스타일 하나를 정하고 끝까지 지킵니다. 색, 글꼴, 이징은 제품의 디자인 토큰에서 가져옵니다.
모션은 `(t, params) → 스타일` 순수 함수로 씁니다. 엔진 폴더의 `motions/`(`iris`, `_lib/ease.ts`)가 예시입니다. 아래 동작 중 모듈이 없는 것은 먼저 그 작품의 `scene.ts`에 순수 함수로 쓰고, 두 번째 작품에서 또 필요하면 골든 값 테스트와 함께 `motions/<모듈>/`로 올립니다.

## Carry: 기본 경계

영상은 한 테이크처럼 흘러갑니다. 비트 경계마다 이미 화면에 있던 무언가가 살아남아 다음 비트로 눈에 띄게 움직이거나 커집니다. carry 검사(`pipeline/carry.ts`)는 살아남은 요소가 화면 대각선의 2% 이상 움직이거나 10% 이상 커지면 **carried**, 화면의 3% 이상 크기로 그대로 있으면 **anchored**(절반 점수), 아무것도 안 남으면 **bare**로 셉니다. 점수 = (carried + anchored/2) ÷ 경계 수, 0.5 미만 FAIL, 0.7 미만 WARN.

잘 되는 carry
- **정체성으로**: 한 요소가 다음 비트의 주인공이 됩니다. 누른 버튼이 결과가 되고, 단어가 위로 올라가며 작아져 다음 줄의 라벨이 됩니다(`productions/carry-demo`).
- **크기로**: 카메라가 카드 안으로 밀고 들어가 카드가 곧 장면이 됩니다. 아이리스는 빈 페이지 위가 아니라 살아남은 요소에서 열립니다.
- **원인으로**: 손이 다음 선택지를 끌어오고, 포물선으로 다음 칸에 뛰어듭니다.
- **로고로 접기**: 끝에서 등장 요소들이 로고로 모입니다.
- **한 자리에 고정**: 단어 하나가 같은 픽셀에 머물고 그 밑의 장면만 바뀝니다(`productions/wordcut`, 측정 드리프트 0.11px 이하).
- 커서·손은 가장 싼 운반체입니다. 자신이 일으킨 경계를 넘는 동안 화면에 남겨 둡니다.

carry가 아닌 것(bare로 셈): 각 페이지가 움직여도 페이지 다음 페이지, 숨김·표시 전환, `@remotion/transitions`의 장면 교체, 결과를 미리 보여 주고 원래 화면으로 돌아오기. bare는 몰아치기(1.5초 안에 큰 변화 3번 이상) 안이나 엔드카드로 갈 때만 씁니다.

## 리듬

컷 길이는 4배 이상 차이 나게 하고 같은 길이를 반복하지 않습니다. 완전히 멈춘 구간(프레임의 25% 이상, 1초 이상 한 번)이 있어야 움직임이 착지합니다. 같은 방식으로 끝나는 컷을 두 번 연달아 두지 않습니다. 레퍼런스가 있으면 숫자는 `ref/targets.json`이 정합니다(`references/reference-analysis.md`).

## 깔끔한 제품 스타일 (기본)

- 평평한 브랜드 팔레트, 행동 색 하나는 "지금 해 보세요" 순간에만. 크기 단계가 분명한 큰 글자, 숫자는 브랜드 고정폭 글꼴.
- 움직임: 살짝 블러가 낀 상승, 도착에만 오버슈트, 실제 숫자의 카운트업, 인용 근거 위의 형광펜, 결과 막대 상승.
- 카메라: 비트 안에서 느리게 밀기, 공개 직전 블러 줌. 영상 전체에 카메라 하나.

## 애니메이션 PV 스타일 ("애니처럼")

컷은 적고 길게, 컷 안에서 일이 더 많이 일어납니다. 예비 동작 → 동작 → 여운 → 정지.
- 큰 순간 뒤의 **집중선**은 2프레임마다 다시 그립니다.
- **임팩트 프레임**: 큰 타격마다 2프레임 반전.
- **슬램**: 글자·로고가 넘쳤다가 눌렸다가 자리 잡고, 안쪽 레이어만 흔듭니다.
- **정지**: 극적인 대사 뒤 모든 움직임을 멈추고 채도를 빼고(`saturate(0) brightness(.6)`) 음악도 끊습니다.
- **더치 앵글**(−2~−4°), 캐릭터 대사는 **말풍선**.
- **패럴랙스**: 같은 물체를 크기·속도·블러가 다른 3겹으로.
- **동작에서 컷**: 충돌 프레임에서 정확히 컷(bare이므로 몰아치기 안에서만).

## bare 경계 (몰아치기와 엔드카드에만)

중간 지점을 비트에 맞춥니다. 어느 엔진에서나 `t`로 계산하는 스타일입니다.

| 경계 | 방법 |
|---|---|
| 아이리스 | 다음 레이어 `clip-path: circle(0% at x y) → circle(75~150% at x y)`, 0.4초 (`motions/iris`) |
| 커튼 | 다음 레이어 `clip-path: inset(0 0 100% 0) → inset(0)` |
| 차오름 | 다음 레이어 `clip-path: inset(100% 0 0 0) → inset(0)` |
| 밀기 | 이전 레이어가 화면 폭만큼 나가고 새 레이어가 들어옴 |
| 스미어 | 어두운 판이 `skewX(-25deg)`로 화면을 쓸고 지나감 |

이 위에 두 레이어를 넘어 움직이는 요소가 하나 있으면 carry가 됩니다(carry-demo가 아이리스로 그렇게 합니다).
