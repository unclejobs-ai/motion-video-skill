# 캐릭터 시트

## 시트에 들어갈 것
- [ ] 정면, 측면, 뒷면
- [ ] 표정 6종 (기본, 웃음, 놀람, 진지함, 슬픔, 화남)
- [ ] 의상 전체와 소품 (안경, 모자, 가방 등)
- [ ] 색상: 머리, 눈, 상의, 하의, 소품을 헥스 값으로 기록
- [ ] 배경은 단색, 글자·라벨 없음

## 외형 고정문 (character.txt)
한 문단으로 쓰고, 이후 모든 프롬프트에 수정 없이 붙입니다. 상의·하의 색을 적습니다.

형식: `<머리 모양·색>, <안경 모양 또는 없음>, <상의 종류·색>, <하의 종류·색>, <소품>, <체형·나이대>`

- 머리: <모양·색 #hex>
- 얼굴: <안경, 수염, 눈 색>
- 상의: <종류·색 #hex>
- 하의: <종류·색 #hex>
- 소품: <소품>
- 체형·나이대: <체형·나이대>

## 키프레임 합격 기준 (시트와 나란히 놓고 확인)
- [ ] 얼굴 윤곽과 눈 모양이 시트와 같습니다
- [ ] 머리 모양과 색이 같습니다
- [ ] 안경·소품의 유무와 모양이 같습니다
- [ ] 상의·하의 색과 구조가 같습니다
- [ ] 같은 이미지에 닮은 인물이 추가로 나오지 않습니다

## 목소리 고정
- 도구: <도구 이름>
- 음성 ID: <ID> (모든 대사에 이 ID만 사용)
- 복제 음성인 경우: 본인 또는 사용 허락을 받은 사람의 목소리 [ ]
