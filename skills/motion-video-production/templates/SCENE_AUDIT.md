# 장면 점검표

## 프레임 스트립 읽는 법
클립마다 `키프레임, 0초, 1.0초, 1.5초, 2.0초, 3.0초`를 한 줄에 놓고 왼쪽부터 비교합니다. 시작 화면이 같아도 1~2초 뒤에 상의 색, 안경, 머리가 바뀌는 일이 있으므로 0초 프레임만 보고 통과시키지 않습니다. 확인하지 못한 항목은 추측하지 않고 "확인 못 함"이라고 적습니다.

판정 코드: `ok` 그대로 사용 · `trim` 쓸 수 있는 구간만 사용 · `redo` 재생성 · `replace` 다른 키프레임으로 교체

## 1. 컷별 점검
| # | 클립 | 판정 | 문제 (구체적으로) | 수정안 (사용 구간 `@1.2 for 2.0`, 새 프롬프트, 교체 키프레임 ID) |
|---|---|---|---|---|
| 1 | <01> | <ok> | <없음> | <없음> |

## 2. 결함 체크리스트 (컷마다)
- [ ] 사물이 거꾸로 움직임 (열렸다 닫히고 다시 열림)
- [ ] 손·손가락 변형, 타이핑 떨림
- [ ] 외형 변화 (안경, 머리, 의상, 눈 색)
- [ ] 후드·소매·머리카락이 녹아내리듯 흐물거림
- [ ] 인물·소품이 사라졌다 나타남
- [ ] 갑작스러운 조명 변화
- [ ] 시간·장소 점프 (직전 컷과 연결이 맞는가)
- [ ] 요청한 동작과 실제 동작이 다름

## 3. 사용하지 않은 키프레임
| 키프레임 | 내용 | 판단 (넣기 / 버리기와 이유) |
|---|---|---|
| <ID> | <내용> | <판단> |

## 4. 검수 기록
motion-video-production 스킬의 단계 검사를 쓸 때만 적습니다. 프레임 스트립과 컨택트 시트를 실제로 본 뒤에만 적습니다.

`qa/clips-review.md`
```
REVIEWED: <이름> <YYYY-MM-DD>
<클립 이름>: ok
<클립 이름>: trim @1.2 for 2.0
```
판정은 `ok`, `trim`, `redo`, `replace` 중 하나입니다. `redo`, `replace`가 남아 있으면 단계 검사를 통과하지 못합니다. 키프레임이 없는 클립은 `nokey: <클립 이름>` 줄로 허용합니다.

`qa/review.md` (최종본을 만든 뒤에 작성)
```
REVIEWED: <이름> <YYYY-MM-DD>
컨택트 시트 <00>칸 확인, <본 결과 한 줄>
```
